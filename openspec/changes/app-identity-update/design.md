## Context

当前 BeatMeter app 使用的是开发初期设置的临时品牌元素：
- 名称：BeatMeter（仅英文）
- 图标：开发时使用的临时图标
- 启动画面：简单的启动图

项目使用 Expo 框架，需要准备符合 iOS、Android、Web 多平台的图标资源。

## Goals / Non-Goals

**Goals:**
- 实现 App 名称国际化：中文"节拍器" + 英文"BeatMeter"
- 生成一套完整的品牌图标（适配 iOS、Android、Web）
- 设计简洁专业的启动画面
- 更新相关配置文件

**Non-Goals:**
- 不修改现有代码逻辑
- 不添加新的功能
- 不改变 app 的核心交互和用户体验

## Decisions

### 1. 图标生成方案

**决定**：使用 AI 生成 1024x1024 主图标，然后通过工具生成各平台所需尺寸

**理由**：
- AI 可以快速生成高质量的视觉设计
- 1024x1024 是 App Store 的标准尺寸，可以向下缩放
- 避免了手动设计的成本

**替代方案考虑**：
- 手动设计：需要设计技能，时间成本高
- 使用现成图标库：缺乏独特性

### 2. 图标设计方向

**决定**：节拍可视化 + 音乐元素 + 科技感

**设计关键词**：
- 节拍、节奏、心跳波形
- 音符、 metronome 摆锤
- 深色背景、霓虹色调（符合 app 的 dark 主题）
- 简洁、扁平化

### 3. 启动画面设计

**决定**：使用独立的静态 Logo 启动画面，不额外加入文字

**布局**：
```
┌─────────────────────────┐
│                         │
│                         │
│      [Logo 图标]        │
│                         │
│                         │
└─────────────────────────┘
```

**技术实现**：
- 使用 Expo splash screen 配置
- 背景色：#0A0E1A（与现有主题一致）
- 静态图片方式，兼容性好
- 基于 `assets/logo.png` 生成专用 `splash-icon.png`，增大留白避免启动页过满

### 4. 配置文件更新

更新 `app.json` / 平台资源中的字段：
- `name`: "BeatMeter"（默认显示名 / fallback）
- `slug`: "beatmeter"（URL/内部标识）
- `ios.infoPlist.CFBundleDisplayName`: "节拍器"
- Android `res/values-zh/strings.xml`: "节拍器"
- Android `res/values-en/strings.xml`: "BeatMeter"

## Risks / Trade-offs

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| AI 生成的图标不符合预期 | 中 | 需要多次迭代 | 提供详细的提示词，明确风格要求 |
| 图标尺寸缩放后模糊 | 低 | 影响美观 | 使用 1024x1024 原图，按需缩放 |
| 中文名在某些系统显示异常 | 低 | 影响用户体验 | 使用官方推荐的多语言配置方式 |
