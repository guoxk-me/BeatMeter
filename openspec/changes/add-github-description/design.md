## Context

BeatMeter 是一个纯 AI 生成的 Expo + React Native 节拍器应用。当前 GitHub 仓库缺少项目描述，需要添加 README.md 开头的项目描述段落，让访问者快速了解项目。

## Goals / Non-Goals

**Goals:**
- 在 README.md 顶部添加项目描述段落
- 明确注明"纯 AI 生成"编写
- 描述核心功能：BPM 控制、节拍播放、自定义 WAV 导入等

**Non-Goals:**
- 不修改现有代码
- 不添加新功能
- 不改变项目架构或依赖

## Decisions

1. **描述位置**: 放在 README.md 最顶部，作为开篇介绍
2. **描述风格**: 简洁专业，突出 AI 生成和核心功能
3. **语言**: 使用英文描述（GitHub 国际化标准）

## Risks / Trade-offs

- **风险**: 描述内容可能需要根据项目发展更新
  - **缓解**: 描述聚焦于核心功能，较为稳定
