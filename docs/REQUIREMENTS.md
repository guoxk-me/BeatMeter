# BeatMeter 节拍器应用 - 产品需求文档

## 📋 产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | BeatMeter |
| 产品类型 | 移动应用（React Native / Expo） |
| 核心价值 | 帮助跑步/健身爱好者通过节拍同步控制步频，提升运动效率 |
| 目标平台 | **Android 优先**，iOS后续 |
| 框架 | Expo SDK 52 |

---

## 👤 用户画像

### 核心用户：跑步/健身爱好者

| 维度 | 描述 |
|------|------|
| 年龄 | 20-45岁 |
| 使用场景 | 户外跑步、健身房训练 |
| 痛点 | 跑步时步频不稳定，长距离后节奏混乱 |
| 需求 | 简单易用的节拍引导，无需复杂设置 |
| 技术熟悉度 | 中等，会使用常见运动App |

### 典型使用场景

1. **晨跑**：启动App → 选择"轻松跑"160BPM → 开始跑步
2. **训练间歇**：临时调整BPM从170→180冲刺
3. **健身房**：关闭声音，只开振动，避免打扰他人
4. **马拉松**：后台播放维持长时间节拍，配合音乐同步

## 📏 验收标准

### 功能验收

| 验收项 | 标准 |
|--------|------|
| BPM调节 | 滑块拖动流畅，数值实时更新，范围40-220有效 |
| 播放控制 | 点击播放立即开始，点击暂停立即停止，无延迟感 |
| 音频滴答 | 每拍间隔精确，延迟<50ms，无明显漏拍 |
| 触觉反馈 | 振动与音频同步，支持开关立即生效 |
| 预设按钮 | 点击预设→自动设置对应BPM并播放 |
| 设置持久化 | 重启App后，BPM、振动开关恢复上次状态 |
| 后台播放 | 切换到后台时节拍继续播放，不中断 |
| 通知栏 | 显示当前BPM，提供播放/暂停/停止控制 |

## 🔧 关键技术方案

### 1. 音频实现

- 使用 `expo-av` 预加载短音效
- 启动时加载~50ms的滴答音效到内存
- 音效文件放在 `assets/sounds/` 目录

### 2. 触觉反馈

- 使用 `expo-haptics` 的 `impactAsync`
- 支持关闭/开启

### 3. 设置存储

- 使用 `@react-native-async-storage/async-storage`
- 存储结构：
  ```json
  {
    "bpm": 170,
    "hapticEnabled": true,
    "volume": 0.8
  }
  ```

### 4. BPM计算

```typescript
// 节拍间隔计算
const intervalMs = 60000 / bpm;
```

### 5. 后台播放方案

| 平台 | 方案 |
|------|------|
| **Android** | 前台服务 + 通知栏 |
| **iOS** | 音频后台模式 + 背景播放 |
