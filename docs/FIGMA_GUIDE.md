# Figma 绘制指南

## 打开 Figma

1. 访问 https://figma.com
2. 登录您的账号
3. 点击 "New Project" 创建新项目

---

## 页面结构

请按照以下结构绘制 BeatMeter 应用界面：

### 1. 画布设置
- 画布尺寸：**375 x 812** (iPhone X/11/12/13/14 标准)
- 背景色：`#0A0E1A` (深邃夜空蓝)

---

### 2. 顶部区域 (y: 60)

**A. 装饰性光晕**
- 位置：画布顶部中央
- 形状：圆形，直径 200px
- 颜色：`#00F5D4`，透明度 15%
- 模糊：80px (Blur)
- 位置：y: -50

---

### 3. BPM 显示区域 (y: 120)

**B. BPM 数字**
- 文字："170" (示例)
- 字体：SF Pro Display / System Bold
- 大小：120px
- 颜色：`#FFFFFF` (播放中 `#00F5D4`)
- 居中对齐

**C. BPM 标签**
- 文字："BPM"
- 字体：System Semibold
- 大小：18px
- 颜色：`rgba(255,255,255,0.7)`
- 字母间距：4px
- 位置：BPM数字下方 8px

**D. 脉冲光环** (播放时显示)
- 形状：空心圆环
- 尺寸：220 x 220px
- 边框：3px
- 颜色：`#00F5D4`
- 位置：BPM数字后方居中

**E. 节拍指示器**
- 8个小圆点，水平排列
- 圆点尺寸：12 x 12px
- 间距：12px
- 第一拍颜色：`#00F5D4`
- 其他拍颜色：`#00C4A7`
- 透明度：当前拍 100%，其他拍 50%
- 位置：BPM标签下方 20px

---

### 4. BPM 调节区域 (y: 340)

**F. 滑块轨道**
- 宽度：屏幕宽度 - 80px = 295px
- 高度：6px
- 圆角：3px
- 颜色：`#1A1F35`

**G. 滑块进度**
- 宽度：根据BPM比例 (当前BPM-40)/180
- 颜色：`#00F5D4`

**H. 滑块 Thumb**
- 圆形：32 x 32px
- 颜色：`#00F5D4`
- 投影：#00F5D4 50% 透明度，模糊 8px

**I. 最小/最大值标签**
- 左侧："40"
- 右侧："220"
- 字体：14px, Semibold
- 颜色：`rgba(255,255,255,0.4)`

---

### 5. 预设区域 (y: 400)

**J. 区域标题**
- 文字："跑步预设"
- 字体：14px, Semibold
- 颜色：`rgba(255,255,255,0.4)`
- 字母间距：2px
- 大写

**K. 预设按钮 (2x2 网格)**
- 按钮尺寸：(屏幕宽度 - 72) / 2 = 151.5px 宽
- 高度：80px
- 圆角：16px
- 背景：`#1A1F35`
- 边框：2px

**预设1 - 热身**
- 边框色：`#00F5D4`
- 标签："热身"
- BPM："140"

**预设2 - 节奏跑**
- 边框色：`#FF006E`
- 标签："节奏跑"
- BPM："170"

**预设3 - 冲刺**
- 边框色：`#FF9500`
- 标签："冲刺"
- BPM："190"

**预设4 - 放松**
- 边框色：`#9D4EDD`
- 标签："放松"
- BPM："160"

---

### 6. 播放控制区域 (y: 540)

**L. 停止按钮**
- 形状：正方形 56x56px，圆角 28px
- 背景：`#1A1F35`
- 边框：2px, `rgba(255,255,255,0.1)`
- 图标：白色方形 20x20px，圆角 4px
- 位置：左侧

**M. 播放/暂停按钮**
- 形状：圆形 80x80px
- 背景：渐变 `#00F5D4` → `#00C4A7` (播放中 `#FF006E` → `#C90055`)
- 投影：主色 40% 透明度，模糊 20px
- 播放图标：白色三角形
- 暂停图标：两个白色矩形
- 位置：中央

---

### 7. 设置区域 (y: 640)

**N. 设置面板背景**
- 圆角：20px
- 背景：`#1A1F35`
- 内边距：8px

**O. 设置项**
- 行高：50px
- 背景色：`#1A1F35` (点击时 `rgba(255,255,255,0.05)`)
- 圆角：12px
- 左侧图标：📳 或 🔊
- 标签文字：16px, Medium, `#FFFFFF`

**设置项1**
- 图标：📳
- 标签："触觉反馈"
- 右侧：开关 Toggle

**设置项2**
- 图标：🔊
- 标签："音效"
- 右侧：开关 Toggle

---

### 8. 开关组件

**Toggle off**
- 尺寸：50 x 30px
- 圆角：15px
- 背景：`#232942`
- 滑块：24 x 24px 圆形，白色

**Toggle on**
- 背景：`#00F5D4`
- 滑块位置：右侧
