# BeatMeter UI 专业设计方案

## 1. 设计理念

**概念方向：霓虹脉冲 (Neon Pulse)**

选择一种**运动 + 夜店能量**的独特美学方向，区别于普通的健身App：

- **视觉灵感**：将跑步时的脚步声转化为视觉脉冲，借鉴电子音乐现场的灯光节奏感
- **核心记忆点**：每一次节拍都伴随视觉"脉冲波"扩散，让跑步节奏"看得见"
- **情绪**：充满活力的夜跑场景，霓虹灯在黑暗中跳动

## 5. 组件说明

- 120px超大字体
- 播放时脉冲动画
- 霓虹发光效果

### 5.2 节拍指示器

- 2x2网格布局
- 每种颜色对应不同步频
- 选中状态发光

### 5.5 播放控制
- 停止按钮(方形)
- 播放/暂停按钮(圆形)
- 渐变背景

### 5.6 设置面板
- 触觉反馈开关
- 音效开关

## 6. 动画效果

### 脉冲动画
- 每次节拍触发
- 缩放1.0 → 1.08 → 1.0
- 持续时间: 280ms
- 播放时BPM数字和脉冲环同时动画

### 按钮动画
- 按下缩放0.95
- 弹簧回弹
- 触觉反馈配合

### 状态过渡
- 播放→暂停: 颜色渐变
- 预设切换: 边框发光

## 8. 设计要点总结

| 要素 | 实现方式 |
|------|----------|
| **BPM可见性** | 120px超大字体，跑步时一眼可读 |
| **户外高对比** | 深色背景+霓虹亮色，户外强光下清晰 |
| **单手操作** | 底部控制区，大按钮易触达 |
| **运动感** | 每次节拍脉冲动画，视觉化节奏 |
| **独特记忆点** | 霓虹美学 + 脉冲光圈 + 节拍可视化 |
| **预设快捷** | 4个跑步常用步频，一键切换 |
