# BeatMeter UI 设计方案

## 1. 页面布局设计

### 整体结构

采用**单页面 + 底部设置**模式，核心操作都在一个界面完成，符合"跑步时单手操作"的需求。

```
┌─────────────────────────────┐
│         状态栏              │
├─────────────────────────────┤
│                             │
│    ┌─────────────────┐      │
│    │     180         │      │  <- BPM 大数字显示
│    │    BPM          │      │
│    └─────────────────┘      │
│                             │
│    ○ ○ ○ ○ ● ○ ○ ○ ○       │  <- 节拍可视化指示器
│                             │
│   [ -1 ]    ──────    [ +1 ]│  <- BPM微调按钮
│                             │
│    ════════════════         │  <- BPM 滑块 (40-220)
│                             │
├─────────────────────────────┤
│                             │
│   [▶]    [⏸]    [⏹]        │  <- 播放控制按钮
│                             │
├─────────────────────────────┤
│                             │
│  [🚶步行] [🏃轻松] [⚡节奏] [🔥冲刺] │  <- 4个预设按钮
│   110     160     170     180
│                             │
├─────────────────────────────┤
│                        [⚙] │  <- 设置入口
└─────────────────────────────┘
```

### 布局层级

| 区域 | 占比 | 说明 |
|------|------|------|
| BPM 显示区 | 30% | 视觉焦点，大字体 |
| 控制区 | 25% | 播放/暂停/停止 |
| 预设区 | 20% | 4个快捷按钮 |
| 调节区 | 20% | 滑块+微调 |
| 设置入口 | 5% | 右下角 icon |

## 2. 视觉设计方向

### 配色方案 - "运动活力"风格

采用**高对比度深色主题**，户外强光下依然清晰可见。

```typescript
// 颜色系统
const colors = {
  // 主背景 - 深色护眼
  background: '#0D0D0D',
  surface: '#1A1A1A',
  surfaceElevated: '#262626',
  
  // 主题色 - 活力橙红
  primary: '#FF6B35',        // 主按钮、强调
  primaryDark: '#E55A2B',    // 按下状态
  secondary: '#00D4AA',      // 播放中指示
  
  // 文字色
  textPrimary: '#FFFFFF',
  textSecondary: '#999999',
  textMuted: '#666666',
  
  // 状态色
  success: '#00D4AA',
  warning: '#FFB800',
  error: '#FF4757',
  
  // 预设按钮色
  presetWalk: '#4ECDC4',     // 青色 - 步行
  presetEasy: '#45B7D1',     // 蓝色 - 轻松跑
  presetTempo: '#96CEB4',    // 绿色 - 节奏跑
  presetSprint: '#FF6B6B',  // 红色 - 冲刺
};
```

### 字体选择

| 元素 | 字体 | 大小 | 权重 |
|------|------|------|------|
| BPM 数字 | System (Bold) | 96pt | 700 |
| BPM 标签 | System | 18pt | 400 |
| 预设名称 | System | 14pt | 600 |
| BPM 值 | System | 12pt | 400 |

## 4. 交互设计

### 手势操作

| 操作 | 区域 | 行为 |
|------|------|------|
| 滑动 | 滑块区域 | 调节 BPM |
| 点击 | 滑块轨道 | 跳转至点击位置 |
| 点击 | ±1 按钮 | BPM ±1 |
| 长按 | ±1 按钮 | 连续加减 |
| 点击 | 预设按钮 | 切换至预设 BPM 并播放 |

### 触觉反馈点

| 场景 | 反馈类型 |
|------|----------|
| 每次节拍 | Heavy |
| 点击播放/暂停 | Medium |
| 点击停止 | Light |
| 切换预设 | Medium |
| 到达BPM边界 | Warning |

### 状态变化动画

| 状态 | 动画 |
|------|------|
| 播放 → 暂停 | 主按钮：缩放 0.95 + 颜色渐变 |
| 暂停 → 播放 | 主按钮：缩放 1.05 + 脉冲 |
| 切换预设 | 按钮：缩放 0.9 → 1.0 |
| 节拍指示 | 当前拍：放大 1.3 + 高亮 |
