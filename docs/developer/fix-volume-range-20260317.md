# 音量范围调整

## 概述
将音量档位从 0-3 调整为 0-6，并同步更新设置持久化层的 clamp 范围。

## 产出
- 设置面板音量档位更新为 0 到 6 的整数档位
- 持久化设置中的音量限制上限更新为 6

## 变更文件
- `src/components/SettingsPanel.tsx` - 更新音量档位数组
- `src/hooks/useSettings.ts` - 更新音量 clamp 上限
